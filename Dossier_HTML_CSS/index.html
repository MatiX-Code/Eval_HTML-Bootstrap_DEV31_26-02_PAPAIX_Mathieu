Pourquoi apprendre HTML/CSS ?

Les langages HTML et CSS est fondamental pour toute personne souhaitant s'initier au développement web. Ces technologies constituent la base de la création de sites internet, permettant de structurer et de styliser des pages web. En maîtrisant ces outils, vous posez les fondations nécessaires pour explorer des concepts plus avancés en programmation web, comme l'utilisation d'interfaces dynamiques avec JavaScript ou la gestion de bases de données. Cette compréhension initiale est donc essentielle pour évoluer dans le monde du développement numérique

Les Balises

Pour pouvoir créer un site Web, nous devons donc commencer a créer un fichier HTML qui est la structure, le squelette du site. Pour cela nous devons apprendre le language pour pouvoir écrire et créer cette structure. Nous utiliserons donc plusieurs balises pour les différents éléments que peut comporter le site

    Les bonnes pratiques & astuces !

    Afin d'avoir un code HTML à la fois performant et propre, je te conseille de commenter ton code ( il n'apparait pas sur ton site mais t'aide à comprendre ce qui a été fait sans lire tout ton code). Pense à intender ton code : organiser celui ci de cette façon permet de bien distinguer les différents niveaux hiérarchiques. Ce n'est pas tout : l'utilisation de balise sémantiques est trés recommandé. Cela permet de voir les différentes parties de ton site ( header, footer, nav, main, article...). N'oublie pas de rajouter un atribut alt sur tes images pour une meilleure accessibilité. Le plus important est de pratiquer, et si tu devais te tromper, recommence ! Tu as droit à l'erreur ! Inspire toi des autres, recherche et tu deviendras un excellent développeur Web !
